JavaScript闭包实战：数据私有化与函数工厂

闭包让内部函数访问外部函数的变量，即使外部函数已经执行完毕。这是因为JS的垃圾回收不会回收还被引用的变量。

典型用途：数据私有化。用闭包模拟私有变量，外部只能通过暴露的方法操作，不能直接修改。比如计数器：function counter() { let count = 0; return { inc: () => ++count, get: () => count }; }。外部拿到counter后，只能通过inc和get操作count，不能直接改。

函数工厂：用闭包生成特定功能的函数。比如创建多个带前缀的日志函数：function createLogger(prefix) { return (msg) => console.log(`[${prefix}] ${msg}`); }。每个logger有自己的prefix闭包。

防抖和节流也是闭包应用：用闭包保存定时器状态。理解闭包，才能写出模块化、数据安全的JS代码。
