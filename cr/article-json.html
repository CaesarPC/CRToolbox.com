JSON格式化是什么？为什么程序员都需要它

Cr工具站 · 技术教程

你有没有见过这样一堆挤在一起的数据：{"name":"小明","age":18,"city":"深圳"}？

这就是 JSON。它是网页和服务器之间交换数据最常用的格式。

API 返回的 JSON 数据经常挤成一团，没有换行没有缩进，人眼根本看不懂哪里是哪里。格式化工具就是把这一团数据变成有缩进、有换行的整齐格式，让你一眼就能看清结构。

1. 快速看清数据结构，找字段不用翻来翻去

2. 检查 JSON 有没有语法错误（少个括号、多个逗号）

3. 调试接口的时候，快速定位哪个字段出了问题
