# 递归与动态规划：算法面试与实战中的核心思维

递归和动态规划是编程算法中最重要也最让人头疼的两个概念。很多人面试时被要求写斐波那契数列或者爬楼梯，写出来了但说不清为什么这么写。递归是一种思维方式——把大问题拆解成同结构的小问题；动态规划是一种优化手段——把重复计算的中间结果存起来，避免重复劳动。理解这两个概念，不只是为了面试，更是为了写出高效的代码。

## 一、递归：自己调用自己

递归的核心思想很简单：一个问题可以拆成一个或多个子问题，子问题和原问题结构相同，只是规模更小。当子问题小到不能再拆的时候，直接给出答案（递归终止条件）。

最经典的递归例子是阶乘：n! = n * (n-1)!，终止条件是0! = 1。写代码就是：function factorial(n) { if (n === 0) return 1; return n * factorial(n-1); }。

递归有两个要素：基线条件（什么时候停止）和递归条件（怎么拆成子问题）。缺了基线条件就无限递归，栈溢出。

递归的好处是代码简洁优雅，树的遍历、分治算法、深度优先搜索天然适合递归。缺点是每次函数调用都有栈空间开销，递归太深会栈溢出。能写成递归的问题，往往也能写成迭代（用栈数据结构模拟），看哪个更直观。

## 二、斐波那契：递归的性能陷阱

斐波那契数列f(n) = f(n-1) + f(n-2)，f(0)=0, f(1)=1。用递归写特别简单：function fib(n) { if (n < 2) return n; return fib(n-1) + fib(n-2); }。

但这个写法的时间复杂度是指数级的O(2^n)。为什么？因为f(5)要算f(4)和f(3)，f(4)要算f(3)和f(2)——f(3)被算了两遍。n越大，重复计算的次数爆炸式增长。算fib(40)可能要几秒钟，fib(50)就完全跑不动了。

问题出在：同一个子问题被重复计算了无数次。解决办法就是把算过的结果存起来。

## 三、记忆化：递归的优化

最简单的优化是加一个缓存（Memoization）。算过的结果存到一个对象里，下次要算同一个子问题时直接从缓存拿，不重复计算。

function fib(n, memo = {}) { if (n < 2) return n; if (memo[n]) return memo[n]; memo[n] = fib(n-1, memo) + fib(n-2, memo); return memo[n]; }

加了缓存之后，每个f(n)只算一次，时间复杂度从O(2^n)降到O(n)。这就是动态规划的雏形——把中间结果存起来，避免重复计算。

## 四、动态规划：自底向上

记忆化递归是"自顶向下"——从大问题往下拆，遇到算过的子问题直接返回缓存。动态规划通常是"自底向上"——从最小的子问题开始，一步步往上推，直到算出大问题的答案。

斐波那契的动态规划写法：function fib(n) { if (n < 2) return n; let dp = [0, 1]; for (let i = 2; i <= n; i++) { dp[i] = dp[i-1] + dp[i-2]; } return dp[n]; }

从dp[0]、dp[1]开始，依次算出dp[2]、dp[3]...一直到dp[n]。时间复杂度O(n)，空间复杂度也是O(n)。

还可以再优化空间：其实只需要保留前两个值，不需要整个数组。let a = 0, b = 1; for (let i = 2; i <= n; i++) { let c = a + b; a = b; b = c; } return b;。空间复杂度降到O(1)。

## 五、动态规划的解题框架

遇到一个问题能不能用动态规划，看两个特征：

第一，最优子结构——大问题的最优解可以由小问题的最优解推导出来。比如爬楼梯：到第n阶的最短路径，取决于到第n-1阶和第n-2阶的最短路径。

第二，重叠子问题——求解过程中会反复遇到相同的子问题。如果每个子问题只算一次，那就没必要动态规划了。

解题步骤：1.定义dp数组的含义——dp[i]代表什么。2.写出状态转移方程——dp[i]怎么从dp[i-1]、dp[i-2]推导出来。3.确定初始条件——dp[0]、dp[1]是多少。4.确定遍历顺序——从前往后还是从后往前。

## 六、常见DP问题

爬楼梯：每次可以爬1或2阶，到第n阶有多少种走法？dp[i] = dp[i-1] + dp[i-2]，和斐波那契一模一样。

打家劫舍：一条街的房子，不能偷相邻的两家，最多偷多少钱？dp[i] = max(dp[i-1], dp[i-2] + nums[i])——第i家偷还是不偷，选钱多的方案。

最长公共子序列：两个字符串，最长的公共子序列长度。dp[i][j] = text1[i] === text2[j] ? dp[i-1][j-1] + 1 : max(dp[i-1][j], dp[i][j-1])。

## 七、总结

递归和动态规划不是什么神秘的算法，它们是一种思维方式：把大问题拆成小问题，把重复计算的结果存起来。递归是自上而下想问题，动态规划是自下而上解决问题。很多时候你先用递归想清楚怎么拆，再翻译成动态规划的自底向上写法。

刷题不是目的，目的是训练这种拆解问题的能力。遇到一个复杂问题，先问自己：这个问题能不能拆成同结构的小问题？小问题的答案能不能推导出大问题？如果能，就往递归和动态规划的方向想。
