# SQL入门：增删改查与聚合查询

SQL是操作关系型数据库的语言。不管你用MySQL、PostgreSQL还是SQLite，核心SQL语法几乎一样。掌握基本的增删改查和聚合查询，就能应对80%的日常数据库操作需求。

## 一、查询：SELECT

最基本的查询：SELECT * FROM users——查users表所有列。但实际不要用*，指定需要的列更高效：SELECT id, name, email FROM users。

加条件：WHERE SELECT * FROM users WHERE age > 18 AND city = '北京'。

排序：ORDER BY created_at DESC DESC降序，ASC升序。

限制条数：LIMIT 10 OFFSET 20——分页，取第3页每页10条。

## 二、插入：INSERT

INSERT INTO users (name, email, age) VALUES ('张三', 'zhangsan@example.com', 25);

一次插多条：INSERT INTO users (name, email) VALUES ('a', 'a@a.com'), ('b', 'b@b.com');。

## 三、更新：UPDATE

UPDATE users SET age = 26 WHERE id = 123;

警告：UPDATE不加WHERE会更新全表！执行前先SELECT确认条件对不对。

## 四、删除：DELETE

DELETE FROM users WHERE id = 123;

同样警告：不加WHERE删全表。生产环境执行DELETE前先SELECT看看影响哪些行。

## 五、聚合查询

COUNT(*)统计行数：SELECT COUNT(*) FROM users WHERE city = '北京';。

SUM/AVG/MAX/MIN：SELECT AVG(age) FROM users;。

GROUP BY分组：SELECT city, COUNT(*) FROM users GROUP BY city;——每个城市有多少用户。

HAVING过滤分组：SELECT city, COUNT(*) c FROM users GROUP BY city HAVING c > 100;——只显示用户超过100的城市。

## 六、JOIN：多表关联

订单表有user_id，要查订单和对应的用户名： SELECT orders.id, users.name FROM orders JOIN users ON orders.user_id = users.id;

INNER JOIN只返回两表匹配的行。LEFT JOIN保留左表所有行，右表没匹配的填NULL。

## 七、总结

SQL的核心就这几个动词：SELECT查、INSERT增、UPDATE改、DELETE删。加上WHERE条件、ORDER BY排序、LIMIT分页、GROUP BY聚合、JOIN关联——日常开发够用了。复杂查询先想清楚要什么数据，再从这几个积木组合。
