# 前端CSS预处理器：Sass与Less

原生CSS写大项目很痛苦：没有变量、没有嵌套、没有复用。CSS预处理器扩展了CSS的能力——变量、嵌套、混入、函数——编译成普通CSS浏览器就能跑。Sass是最流行的预处理器。

## 一、变量

原生CSS没有变量（虽然现在CSS变量已经普及了）。Sass： $primary-color: #3498db; .button { color: $primary-color; }

改主题色只改变量一处，全局生效。

## 二、嵌套

原生CSS选择器一层层写：.nav ul li a { }。Sass可以嵌套： .nav { ul { li { a { color: blue; } } } }

编译后自动展开成完整选择器。结构清晰，和HTML层级对应。

## 三、混入（Mixin）

复用一段样式： @mixin flex-center { display: flex; justify-content: center; align-items: center; } .card { @include flex-center; }

## 四、现代趋势

现在很多项目用CSS-in-JS（Styled Components）或CSS Modules替代预处理器。Tailwind CSS更是直接用原子化class，连预处理器都不太需要了。但Sass的思想——变量、嵌套、复用——影响了所有后来者。

## 五、总结

CSS预处理器解决了原生CSS的复用和组织问题。新项目可以根据团队偏好选Sass或Tailwind，但理解预处理器的核心概念（变量、嵌套、混入），看任何样式方案都不会陌生。
