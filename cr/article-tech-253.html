# 前端Fetch API：现代网络请求

XMLHttpRequest是老派的AJAX方式，写起来回调嵌套。现代前端用Fetch API——Promise风格，简洁优雅。

## 一、基本用法

fetch('/api/users') .then(res => res.json()) .then(data => console.log(data)) .catch(err => console.error(err));

async/await写法更舒服： async function getUsers() { const res = await fetch('/api/users'); const data = await res.json(); return data; }

## 二、POST请求

fetch('/api/users', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: '张三' }) });

## 三、常见坑

fetch不会因为4xx/5xx就reject——只有网络错误才reject。HTTP错误状态码要手动检查： if (!res.ok) throw new Error('HTTP ' + res.status);

超时：fetch默认没有超时。要超时用AbortController： const controller = new AbortController(); setTimeout(() => controller.abort(), 5000); fetch(url, { signal: controller.signal });

## 四、总结

Fetch是现代前端请求数据的标准方式。比XHR简洁，支持Promise和async/await。记住两个坑：HTTP错误要手动检查ok，超时要用AbortController。
