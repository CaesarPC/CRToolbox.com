JavaScript事件委托：利用冒泡减少监听器数量

列表有100个按钮，每个都绑点击事件性能差。事件委托利用事件冒泡，在父元素上绑一个监听器，通过event.target判断是哪个子元素被点击。这样只需要一个监听器，而不是100个。

原理：事件触发后会从目标元素冒泡到父元素。在父元素上监听click，通过event.target找到实际点击的元素。新增的子元素自动享受委托，不需要重新绑定。

优势：减少监听器数量（性能好）；动态添加的元素自动绑定（不需要重新bind）；内存占用低。

实现：父元素.addEventListener('click', e => { if (e.target.matches('.item')) { ... } })。用matches判断点击的是不是目标元素。这是前端优化的常用技巧。
